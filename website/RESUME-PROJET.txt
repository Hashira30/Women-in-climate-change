🚀 DÉMARRAGE RAPIDE :

  1. Ouvrez un terminal et allez dans le dossier :
     $ cd /Users/hashira/Desktop/Association/website

  2. Lancez le serveur local :
     $ python3 -m http.server 3000 --bind 127.0.0.1 --directory public

  3. Ouvrez dans votre navigateur :
     http://localhost:3000

  4. Commencez à modifier les fichiers HTML et voyez les changements en live !
