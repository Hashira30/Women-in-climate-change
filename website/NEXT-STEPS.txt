   Dans index.html :
   └─ <div class="stat-number counter" data-target="0">

🚀 DÉPLOYER SUR UN SERVEUR

1. CHOISIR UN HÉBERGEUR
   ├─ Options recommandées pour les associations :
   │  ├─ OVH, 1&1, Hostinger
   │  ├─ Vercel (gratuit, recommandé pour sites statiques)
   │  └─ Netlify (gratuit, easy setup)
   └─ Budget : 30-100 EUR/an

2. ACHETER UN DOMAINE
   └─ Exemples possibles :
      ├─ wicc-cameroon.cm
      ├─ wicc-yaounde.cm
      ├─ climatfemmes.cm
      └─ ContactTLD local pour plus d'autorité

3. CONFIGURER HTTPS
   └─ Let's Encrypt (GRATUIT)
   └─ Redirection automatique HTTP → HTTPS

4. SOUMETTRE À GOOGLE
   ├─ Google Search Console
   ├─ Soumettre sitemap.xml
   └─ Attendre indexation (~1-2 semaines)

📊 VALIDER LA QUALITÉ

1. LIGHTHOUSE (Chrome DevTools)
   Cible : 90+ Performance, 95+ Accessibility, 100 SEO
   └─ Chrome → F12 → Lighthouse → Analyze

2. MOBILE-FRIENDLY TEST
   └─ https://search.google.com/test/mobile-friendly
   └─ Doit être "Mobile-friendly"

3. VALIDATEUR HTML
   └─ https://validator.w3.org/
   └─ Doit avoir 0 erreur

4. VALIDATEUR SITEMAP
   └─ https://www.xml-sitemaps.com/validate-xml-sitemap.html
   └─ Vérifier que sitemap.xml est bien formé

5. ACCESSIBILITÉ
   └─ WAVE : https://wave.webaim.org/
   └─ Pas d'erreur de contraste ou structure
